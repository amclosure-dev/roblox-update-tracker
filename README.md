Roblox update tracker from nymus (me)

# Installation
  - Start by downloading the source obviously.
  - Extract the source.
  - Open a cmd inside the folder path.
  - In the cmd run ```npm install``` to install everything needed.
  - Then head to ```.env``` file and put there your token, channel id and everything required.


# Get it to work
  - It is pretty straight forward, once you installed everything with ```npm install``` and configured your .env file simply run ```npm start``` to start the bot.
  - To check if it works there is a console with a quick command you can execute yourself: .test windows or .test mac or .test IOS or .test android, that will make the bot send a message like if roblox just updated confirming that the bot works.
